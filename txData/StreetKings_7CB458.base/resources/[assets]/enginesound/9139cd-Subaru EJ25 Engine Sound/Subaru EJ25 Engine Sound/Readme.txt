Description :
This mod replaces the Sultan RS' sound by a Subaru EJ25 one.
It can be used on any car by changing the audioNameHash to SULTANRS in the appropriate vehicles.meta.
For example, it can be used on AlperB's 2004 Subaru Impreza WRX STI : https://www.gta5-mods.com/vehicles/subaru-impreza-wrx-sti-2004-add-on-tuning
It can also be used on Zievs' Add-on 1998 Subaru Impreza 22B-STi Series : https://www.gta5-mods.com/vehicles/1998-subaru-impreza-22b-sti-series-i
I hope you'll enjoy it !

Contact me on my Discord Server : https://discord.gg/KXkzqBc

Installation :
- Extract "Subaru EJ25 Engine Sound.zip"
- Choose the version you want to use by listening at the audio samples in each version 
- Using OpenIV, replace sports_saloon_4_jp_flat4.awc and sports_saloon_4_jp_flat4_npc.awc in in Grand Theft Auto V\mods\update\x64\dlcpacks\mpjanuary2016\dlc.rpf\x64\audio\sfx\dlc_ja16\
- Enjoy the Subaru rumble
