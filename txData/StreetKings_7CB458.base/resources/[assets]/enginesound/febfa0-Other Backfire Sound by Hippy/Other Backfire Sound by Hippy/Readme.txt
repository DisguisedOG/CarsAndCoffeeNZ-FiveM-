Description :
This mod replaces the all the original backfire sounds of the game for the ones I made.
It won't work on some cars (DLC Cars) that have their backfire sounds in their own .awc file.

It also includes the original files. 

I hope you'll enjoy it !
Don't forget to leave a comment and give me some advices on how I could make the mod better, as well as suggestions ! 
Installation instructions can also be found in the Readme file.

Installation : 
- Extract "GTA V Other Backfire Sound by Hippy.zip" anywhere you want
- In OpenIV, go to Grand Theft Auto V/(mods)/x64/audio/sfx/RESIDENT.rpf
- Right click on "vehicles.awc" and click on "Export to opnFormat (.oac)" (Extract it wherever you want). It will create a "vehicles.oac" file and a "vehicles" folder
- Go in the "Other Backfire Sound" mod files you extracted, copy all the content of the "Additional files to copy" folder, and put it in the "vehicles" folder that got created when you extracted "vehicles.awc"
- Go in the folder of version of the mod that you want (in the "Backfire Sounds" folder, then in Version 1, Version 2, or Very old Version), copy all its content, and put it it the "vehicles" folder that got created when you extracted "vehicles.awc"
- Go on OpenIV, and again, in Grand Theft Auto V/(mods)/x64/audio/sfx/RESIDENT.rpf
- Click on "New" (top left) then "Import openFormats"
- Choose the "vehicle.oac" file that got created when you extracted "vehicles.awc", and click Open.
- Click Ok.
- The mod is installed ! You can now close OpenIV and launch your game, and enjoy your new Backfire Sounds !
