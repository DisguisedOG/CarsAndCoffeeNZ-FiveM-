Description :
This mod is made for AitGamers' Lamborghini Huracan : https://www.gta5-mods.com/vehicles/lamborghini-huracan-lp610-4-2015

But you can use it on any car by changing <audioNameHash /> to <audioNameHash>COQUETTE3</audioNameHash> in the appropriate vehicle.meta.

It replaces the engine, blow-off valve and backfire sounds of the car.
IT replaces the soud of the Coquette BlackFin. If you still want the BlackFin to sound like it did originally, follow the optional step.

It also includes the original files.

I hope you'll enjoy it !

Installation :
- Go in "Lamborghini Huracan V10 Engine Sound by Hippy.zip", then in the "Engine Sound" folder
- Replace supercar_12_us_v8.awc and supercar_12_us_v8_npc.awc in Grand Theft Auto V\(mods)\update\x64\dlcpacks\mpluxe2\dlc.rpf\x64\audio\sfx\dlc_lux2\
- If you want to use this engine sound with AitGamers' Lamborghini Huracan, go in Grand Theft Auto V\mods\update\update.rpf\common\data\levels\gta5\ and extract vehicle.meta
- Open it with Notepad and search for "feltzer2", then look for the line <audioNameHash />, and change it to <audioNameHash>COQUETTE3</audioNameHash>
- Save the file and put it back in its original location
- The mod is installed ! You can launch your game, and enjoy your new Lamborghini Huracan V10 Engine Sound !

Optional Step :
Because this mod replaces the Coquette BlackFin's engine sound, the Coquette BlackFin's will have this Lamborghini V10 Engine Sound.
If you want the Coquette BlackFin to sound like it did originally while keeping this mod :
- Go to Grand Theft Auto V\mods\update\x64\dlcpacks\mpluxe2\dlc.rpf\common\data\levels\gta5\ and extract vehicle.meta
- Open it with Notepad and search for "coquette3" (it should be near the beginiing), then look for the line <audioNameHash />, and change it to <audioNameHash>VERLIERER2</audioNameHash>
- This puts the Verlierer's sound on the Coquette BlackFin (which sounds almost identical to the original sound of the Coquette BlackFin)
